# hick-toors — Mobile-Friendly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Every feature usable on a phone with a full-screen map, a ☰ controls panel and a bottom tab bar, while the desktop layout stays unchanged.

**Architecture:** One DOM. `static/index.html` wraps today's header controls (all but brand + Go-to) in `#controls-more` (desktop: `display: contents`), adds a `☰` button and a `#tabbar`. A phone-only `@media (max-width: 760px)` block in `static/style.css` turns `#controls-more` into a full-screen panel, the sidebar into the List tab and dialogs into full-screen sheets. `static/mobile.js` owns tab/panel state and mirrors badges; small hooks in `app.js` / `trips.js` / `vote.js` call it.

**Tech Stack:** vanilla JS, CSS, Leaflet 1.9.4 + Leaflet.draw 1.0.4; Playwright UI check (`channel="chrome"`).

**Spec:** `docs/superpowers/specs/2026-10-11-mobile-design.md` — binding for every value (breakpoint, tab names, sizes, behaviours).
